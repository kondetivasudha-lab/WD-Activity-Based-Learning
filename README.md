# Combined Case Studies

This folder contains the combined project report PDF with the following case studies:

## Case Study 6: Online Shopping Website
- **Project Name:** ShopEase
- **Technologies Used:** HTML, CSS
- **Features:** Navigation bar, seasonal sales banner, product categories, featured products, pricing, ratings, discounts, and special offers.
- **Objective:** To design a user-friendly e-commerce interface for browsing and price comparison.

## Case Study 8: Online Food Ordering Website
- **Project Name:** FoodieHub
- **Technologies Used:** HTML, CSS, JavaScript
- **Features:** Navigation bar, restaurant details, food categories, menu cards, prices, ratings, delivery information, special deals, and customer reviews.
- **Objective:** To design a user-friendly food delivery interface for browsing menus and quick checkout.

## Case 18: The Golden Spoon — Restaurant & Cafe Website
- **Technologies Used:** HTML5, CSS3
- **Design Palette:** Warm beige (#FDFBF7), dark olive (#3F4E38), and gold
- **Features:** Landing banner, brand story, food and beverage menu, restaurant ambiance, chef profiles, guest reviews, table reservation form, opening hours, and footer.
